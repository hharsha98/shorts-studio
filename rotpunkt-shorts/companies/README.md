# Company configs

[`_example.yaml`](_example.yaml) is the neutral schema. Copy it when you start a new company. Its image URLs are placeholders (`example.invalid`), so a render uses the drawn graphics and a closing card without a logo.

Every other file in this folder is a **worked example**: a concept for that company, not an official project and not an endorsement. Before/after numbers in those files are illustrative. The proof card is not read from them. It is fixed in [`template/copy.py`](../template/copy.py).

[`rotpunkt/`](rotpunkt/) holds the scripts and the storyboard for three bilingual Shorts. Those rendered films are not stored in git. The scene code does not import any file in this folder.
